# WebScraper – instalátory FEBA-MONT

Tento repozitář obsahuje pouze instalační balíčky pro Windows a manifesty aktualizací.
Zdrojový kód je spravován samostatně v soukromém repozitáři.

## Instalace

Stáhněte `WebScraper-Setup.exe` ze stabilního vydání v sekci Releases.
Přechod z verze 1.0.4 a starších vyžaduje jednorázovou ruční instalaci.
Nastavení a výsledky se při přeinstalování zachovají.

Dokud není zveřejněné stabilní vydání, nový instalátor není dostupný.
Původní autor aplikace: Ondřej Túma.
